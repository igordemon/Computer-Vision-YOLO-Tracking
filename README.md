# ML Project - Computer Vision Prototype

## Quick start (recommended)

Requirements:
- Docker Desktop
- NVIDIA Driver
- NVIDIA Container Toolkit (for GPU mode)

Run:

Linux:
```bash
chmod +x run.sh
./run.sh
```

Windows:
```bat
run.bat
```

The project will build the environment inside Docker. No Conda or local Python packages are required.

## Local development

Python 3.11 is recommended.

Install:
```bash
pip install -r requirements.txt
```

Run:
```bash
python CV_Project/yolo_depth_tracking.py
```
